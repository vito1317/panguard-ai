# Changelog

All notable changes to the PanGuard AI VS Code extension will be documented in this file.

## [0.1.0] - 2026-04-02

### Added
- Initial release of PanGuard AI VS Code extension
- Real-time security scanning for SKILL.md files
- Support for 71+ threat detection patterns
- CodeLens integration showing security scores
- Interactive security dashboard with WebView
- Status bar widget displaying current security score
- Configurable severity thresholds
- Auto-scan on file save
- Workspace-wide scanning capability
- Inline diagnostics with severity color-coding
- Quick access commands for scanning and dashboard

### Features
- Automatic activation on workspace containing SKILL.md files
- Real-time diagnostics integrated with VS Code problems panel
- Security grade calculation (A-F)
- Finding categorization by severity and type
- Remediation suggestions for findings
- Scan result caching for performance
- Full TypeScript support with proper type safety

### Documentation
- Comprehensive README with installation and configuration
- Command documentation
- Settings documentation
- Security severity level explanations
